A small exact interpreter for make.fun's tiny stack ISA: 32-bit wrapping arithmetic, all eleven trap codes, and byte-exact stdout plus exit code for every program.

## Run it

```sh
node main.ts
```

It reads `MAKEFUN_INPUT_DIR` (default `/input`) and writes `stdout.bin` and `exit.txt` per program into `MAKEFUN_OUTPUT_DIR` (default `/output`).
